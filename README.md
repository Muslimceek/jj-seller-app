# JJ Seller — копия приложения продавца (по записи экрана 24.11.2026)

Мобильное веб-приложение (React + Vite + TypeScript), повторяет экраны JJ Seller:
главная (баланс, статистика Gün/Hafta/Ay/Çeyrek, быстрые действия, последние заказы), Ürünlerim,
Ürün Ekle / Ürün Düzenle (категории-дерево, марки, цвета, размеры, теги, цена/валюта, скидка, тип стока,
фото/видео, описание с «AI ile oluştur», доп. характеристики), Ürün Detayları, Siparişler (6 вкладок),
детали заказа, Analiz, Yeni Çekim, Profil, Profili Düzenle, Finans, Belgeler, Marka belgeleri,
правила листинга, Destek, SSS, Kullanıcı sözleşmesi, выбор языка.

## Запуск
```
npm install
npm run dev
```
Откроется на http://localhost:5190 (на компьютере — в рамке телефона, на телефоне — на весь экран).

## Открыть в Antigravity
File → Open Folder → эта папка (`09_JJ_Seller_App`). Терминал в Antigravity → `npm run dev`.

## Где что
- `src/data.ts` — все данные: товары, заказы, категории, марки, цвета, размеры, суммы.
- `src/App.tsx` — навигация (вкладки + стек экранов, шторки, тосты).
- `src/screens.tsx` — все экраны, кроме формы товара.
- `src/ProductForm.tsx` — добавление и редактирование товара.
- `src/styles.css` — цвета (`--p` — фиолетовый), отступы, компоненты.
- `public/img/` — фото товаров, вырезанные из записи экрана.

Личные данные покупателя и продавца (имя, телефон, почта) заменены на условные.
